# Переход из статистики в карточку прибора

Обновление только для прототипа. Ячейка «Прибор» целиком открывает его карточку: можно нажать на название, модель или свободное место ячейки. Обычно рамка и подсветка отсутствуют; появляются при наведении мыши. Для клавиатуры предусмотрена подсветка фокуса и переход по Enter. На телефоне работает касание.

Переход выполняется в текущей вкладке без полной перезагрузки. Кнопка «Назад» браузера возвращает в статистику с выбранным фильтром. Ctrl/Command+клик сохраняет обычное открытие ссылки в новой вкладке. Для записей без идентификатора прибора ссылка не создаётся.

В архиве четыре изменённых файла прототипа и эта инструкция. Загрузите их в GitHub по тем же путям. На сервере из папки проекта выполните:

```sh
git pull --ff-only
```

Пересборка контейнеров и миграция базы не нужны. Откройте прототип и нажмите Ctrl+F5.

Проверено в Chrome с имитацией API: подсветка только при наведении, нажатие на пустое место ячейки, переход клавишей Enter, возврат в статистику кнопкой браузера. Рабочие данные сервера не изменялись.
