# Исправление статистики прототипа

В архиве только изменения относительно обновления статистики от 07.10.2026. Миграции 043–045 должны быть уже применены.

- История отображается начиная с **07.10.2026, 00:00 по Москве**. Дата фиксированная: завтра история за сегодня не исчезнет.
- Все приборы на руках показываются независимо от даты выдачи. Если старый прибор возвращают начиная с этой даты, его возврат также остаётся в новой истории.
- Старые завершённые выдачи до этой даты скрыты, в том числе из счётчиков фильтров. Данные старого журнала не удаляются.
- Добавлен отдельный столбец **Место использования**, отдельно от проекта. Место сохраняется при выдаче и остаётся после возврата. Если раньше место не сохранилось ни в журнале, ни в открытой выдаче, отображается «Не указано».

После загрузки файлов в GitHub выполните из папки проекта на сервере (предварительно сделав резервную копию базы):

```sh
git pull --ff-only
docker compose exec -T db sh -c 'psql -v ON_ERROR_STOP=1 -1 -U "$POSTGRES_USER" -d "$POSTGRES_DB"' < db/046_equipment_loan_place.sql
docker compose build api
docker compose up -d --no-deps api
```

При ошибке миграции остановитесь. Затем обновите прототип через Ctrl+F5. Перезапуск Caddy, ИСУ и AI не требуется.

Проверки отображения места, его безопасного вывода и одинакового ограничения дат для списка и счётчиков выполнены локально. PostgreSQL здесь недоступен. Проверка настоящих триггеров после миграции с откатом тестовых записей:

```sh
docker compose exec -T db sh -c 'psql -v ON_ERROR_STOP=1 -U "$POSTGRES_USER" -d "$POSTGRES_DB"' < tests/equipment-loans.sql
```
