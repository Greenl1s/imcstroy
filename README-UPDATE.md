# Статистика прототипа: список приборов и раскрываемая история

Изменения относятся к прототипу `/instruments-prototype/`.

## Что изменилось

- «Все приборы»: полный список существующих карточек, включая приборы без выдач. Удалённые карточки не показываются; списанные обозначаются «Списан».
- «В работе»: только карточки, по которым есть незавершённые выдачи. Под ними показываются текущие выдачи.
- Верхняя строка: название, модель/номер, число выдач в проекты, число разных проектов, общее время и текущее состояние.
- Нажатие на название в верхней строке открывает карточку. Нажатие на остальную часть строки либо стрелку раскрывает/сворачивает историю. Стрелкой можно пользоваться с клавиатуры.
- Вложенная история: прибор, сотрудник, проект, место использования, даты и время выдачи/возврата, состояние. Названия во вложенной истории не являются ссылками.
- Более 100 выдач одного прибора загружаются кнопкой «Показать ещё». Итоги сразу учитывают все записи, а не только первую страницу.
- На телефоне таблицы отображаются карточками без горизонтального выхода за экран.

## Как считаются итоги

Сохранена ранее согласованная граница: 07.10.2026, 00:00 по Москве. Учитываются выдачи/возвраты с этой даты и все текущие выдачи независимо от даты начала. Завершённая до этой даты старая история не добавляется.

«Выдач в проекты» — количество отдельных выдач с указанным проектом. Повторная выдача в тот же проект считается ещё одной выдачей. Под числом указано количество разных проектов. Выдачи без проекта видны в истории и учитываются во времени, но не увеличивают число выдач в проекты.

Общее время — сумма интервалов от точного времени выдачи до окончательного возврата, а для текущих выдач — до момента обновления страницы. Длительность выдачи партии не умножается на количество штук. Одновременные отдельные выдачи суммируются. Частично возвращённая партия считается открытой до полного возврата.

Если точного времени выдачи нет, интервал не подменяется полуночью. Показывается «Нет точных данных» либо сумма известных интервалов с пометкой «Без выдач с неизвестным временем». Время обновляется кнопкой «Обновить» или при открытии статистики.

## Применение на сервере

После загрузки файлов в GitHub выполните в каталоге проекта, где находится `docker-compose.yml`, по одной строке:

```sh
git pull --ff-only
docker compose build api
docker compose up -d --no-deps api
docker compose ps api
docker compose logs --tail=40 api
```

Статика прототипа подключена к Caddy из папки `web-prototype`; отдельная сборка интерфейса не требуется. После обновления откройте `/instruments-prototype/?statistics` и выполните Ctrl+F5 на компьютере. На телефоне закройте и снова откройте страницу.

Проверьте: прибор без выдач есть в «Все приборы», верхняя строка раскрывается, имя открывает карточку, вложенные строки не открывают её, «В работе» показывает только незавершённые выдачи. После выдачи/возврата нажмите «Обновить» и проверьте новые итоги.

## Проверки перед передачей

Пройдены проверки синтаксиса Node.js и `node tests/loan-statistics.test.mjs`: форматирование времени, русские окончания, неизвестное время, HTML-экранирование, фильтры, параметры запроса и пагинация.

В Chrome с тестовым API проверены полный список, прибор без выдач, раскрытие/сворачивание мышью и клавиатурой, загрузка следующих записей, переход только из верхней строки, текущие выдачи, повтор запроса после ошибки и ширина мобильного экрана 390 px.

Эти проверки не подключались к вашей рабочей базе. Выполнение нового SQL-запроса на серверном PostgreSQL и реальные итоговые значения нужно проверить после обновления.
