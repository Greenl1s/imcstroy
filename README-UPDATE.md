# Виды экспертиз в проектах и документах

Загрузить в GitHub шесть файлов из папок db и filemanager с сохранением путей.
Этот README в проект добавлять не нужно.

Изменения:
- В ГП и других документах поле вида экспертизы использует справочник базы.
- Выбор проекта подставляет его вид экспертизы. При смене проекта значение обновляется.
- Сохранённый исторический вид не теряется, даже если его нет в текущем списке.
- В тексте ГП окончания видов на -ая/-яя приводятся к форме -ой/-ей.
- Ошибка загрузки справочников показывается явно и не сохраняется в кеше как пустой ответ.
- Миграция переносит четыре прежних варианта ГП в fm_lookups, не удаляя существующие значения и проекты.

Выполнять НА РАБОЧЕМ СЕРВЕРЕ, в папке проекта. Домашний сервер сейчас не обновлять.

1. После загрузки файлов в GitHub:

```sh
git pull --ff-only
```

Если есть конфликт локальных изменений — остановиться, ничего не сбрасывать.

2. Сделать копию базы (значения берутся из контейнера):

```sh
mkdir -p "$HOME/backups/imcstroy"
docker compose exec -T db sh -c 'pg_dump -U "$POSTGRES_USER" -d "$POSTGRES_DB"' > "$HOME/backups/imcstroy/db-before-expertise-types-$(date +%F-%H%M%S).sql"
```

При ошибке pg_dump не продолжать.

3. Применить миграцию:

```sh
docker compose exec -T db sh -c 'psql -v ON_ERROR_STOP=1 -1 -U "$POSTGRES_USER" -d "$POSTGRES_DB"' < db/047_expertise_type_choices.sql
```

4. Пересобрать только ИСУ:

```sh
docker compose up -d --no-deps --build filemanager
docker compose logs --tail=40 filemanager
```

5. Обновить страницу браузера Ctrl+F5. Проверить новый проект, редактирование проекта,
ГП, ходатайство об осмотре, смену выбранного проекта и добавление вида в справочник.

Проверено локально: синтаксис JS; браузерные проверки функций выбора и автоподстановки
с тестовыми ответами API; повторная загрузка после ошибки; генерация DOCX ГП и окончания
четырёх прежних видов. Рабочая PostgreSQL и её данные локально недоступны: выполнение
миграции и полный сценарий сохранения на сервере требуют проверки после обновления.

Если после обновления список пустой, прислать текст сообщения о справочниках и
логи filemanager. Не заменять справочник вручную в HTML.
