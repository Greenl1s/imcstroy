# Сортировка и поиск приборов в статистике прототипа

Применять поверх предыдущих обновлений сгруппированной статистики и возврата из карточки.

## Изменения

- Приборы в статистике сортируются по инвентарному номеру, как в общем списке, с числовым сравнением: 1, 2, 3, … 10. Приборы без инвентарного номера идут в конце по внутреннему номеру карточки.
- Рядом с названием показывается номер: инвентарный либо `#id`, если инвентарный не указан.
- Поиск по названию, номеру карточки, инвентарному номеру, модели и серийному номеру. Регистр не учитывается, «ё» и «е» считаются одинаковыми.
- Поиск работает в «Все приборы» и «В работе». Ввод сразу фильтрует весь загруженный список без новых запросов к серверу и показывает количество совпадений.
- При отсутствии совпадений отображается «Ничего не найдено». Очистка поля возвращает список.
- Поисковая строка сохраняется при переключении разделов и возврате из карточки в рамках открытого приложения. Раскрытая история сохраняется при фильтрации.

## Применить на сервере

В каталоге проекта:

```sh
git pull --ff-only
```

Пересборка контейнеров и миграция базы не нужны. Затем обновите страницу через Ctrl+F5. На телефоне закройте и снова откройте страницу.

## Проверено

Пройдены проверки JavaScript, сортировки 1/2/10 и карточек без инвентарных номеров, поиска по всем полям, регистру и «ё»/«е». В Chrome с тестовым API проверены отсутствие совпадений, очистка поиска, поиск по номеру карточки, сохранение поиска при возврате из карточки, переключение в «В работе» и поиск на мобильном экране. Предыдущие проверки времени, истории и возврата также прошли.
