# Возврат из карточки в исходный список

Обновление прототипа `/instruments-prototype/`. Применять поверх предыдущего обновления «Статистика: список приборов и раскрываемая история».

## Изменения

- Карточка, открытая из статистики, по кнопке «К списку» возвращает в статистику.
- При возвращении без перезагрузки приложения сохраняются раздел «Все приборы» / «В работе», раскрытые истории и положение страницы. Итоги и история запрашиваются заново, чтобы учитывать действия с прибором.
- Карточка, открытая из общего списка или по прямой ссылке, возвращает в общий список приборов.
- Карточка, открытая из списанных приборов, возвращает в списанные. Кнопка возврата из карточки комплекта возвращает к комплектам.
- Источник сохраняется в ссылке на карточку: `?id=10&from=statistics`. Поэтому возврат в статистику работает после обновления карточки и при открытии такой ссылки в новой вкладке. Перезагрузка приложения сбрасывает раскрытые истории и выбранный фильтр.
- Работает на компьютере и телефоне.

## Файлы

Замените в GitHub по тем же путям:

1. `web-prototype/js/app.js`
2. `web-prototype/js/statistics.js`
3. `web-prototype/index.html`
4. `tests/loan-statistics.test.mjs` — проверка ссылки с источником.

Архив содержит только эти изменённые файлы и инструкцию. Изменения в основной версии учёта оборудования не требуются.

## На сервере

В каталоге проекта выполните:

```sh
git pull --ff-only
```

Пересборка контейнеров и миграция базы для этого обновления не нужны: меняется только статика прототипа. Обновите страницу через Ctrl+F5 на компьютере; на телефоне закройте и снова откройте страницу.

## Проверено

Проверены синтаксис JavaScript и `node tests/loan-statistics.test.mjs`. В Chrome на настоящих файлах интерфейса с тестовым API проверены: переход из статистики и возврат кнопкой, сохранение фильтра «В работе» и раскрытой истории, возврат кнопкой браузера, возврат после перезагрузки карточки, прямое открытие карточки с возвратом в список, возврат на мобильном экране.
