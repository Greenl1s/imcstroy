# Табельный учёт 2.1.0

## Главная и справочники

На главной администратора четыре одинаковые по размеру карточки: Табели,
Планирование, Верификация, Контроль. У сотрудников видны только разрешённые
разделы. База данных остаётся в левой панели, карточки на главной у неё нет.

Добавлен справочник «Подразделения». Создаётся только название, затем оно выбирается
из списка при добавлении и редактировании сотрудника. Создать новое подразделение
текстом из карточки сотрудника нельзя — сервер требует запись из справочника.
Существующие текстовые названия при первом запуске автоматически переносятся
в справочник и связываются с сотрудниками; одинаковые названия без учёта регистра
и лишних пробелов объединяются. Созданные месяцы сохраняют прежний текст подразделения.
Изменение названия справочника обновляет только текущие карточки сотрудников.
Нельзя убрать подразделение, пока оно назначено действующим сотрудникам.

Кнопка «Добавить должность» осталась только в справочнике «Должности».
Из интерфейса базы убран прежний справочник работ. Старые записи не удаляются:
они сохраняются для совместимости с ранее созданными табелями.

Название суммы в настройках заменено на
«Среднемесячная заработная плата производственного работника».
Расчёт, сохранённые суммы и исторические значения этим не меняются.

## Блоки, шифры и занятость

Откройте «Работы общих таблиц» и нажмите «Добавить блок». Укажите номер и название.
Внутри блока добавляйте работы: номер в блоке и название. Шифр формируется сервером:
блок 1, работа 1 — 1.1; блок 2, работа 3 — 2.3. Номер автоматически предлагается
следующим свободным; номера архивных записей не переиспользуются.

Напротив каждой работы три квадрата: Командировка, Офис, Общая. Нажатие включает
или выключает соответствующий тип. Можно разрешить несколько типов или не разрешать
ни одного. Эти ограничения независимы от разрешений для должностей.

Прежние работы общих таблиц при обновлении переносятся в блок 1 с последовательными
номерами. В справочнике они получают новые шифры. Уже заполненные ячейки общих таблиц
и готовые табели сохраняют прежние шифры, названия, цвета и расчёты.
Редактирование номера блока обновляет шифры в справочнике, но не сохранённые месяцы.

## Назначение работ должностям

В разделе «Должности» нажмите «Выбрать работы» напротив должности.
Выберите блок, отметьте нужные работы и нажмите «Сохранить блок».
Окно остаётся открытым: можно выбрать следующий блок, отметить работы и снова сохранить.
Перед сменой блока сохраните изменения текущего блока.

Сохранение меняет только выбранный блок и выбранную должность. Назначения других
блоков и должностей сохраняются. Одна работа может быть назначена нескольким
должностям. Под названием работы видно «Назначено: ...» со списком должностей.
При повторном открытии ранее сохранённые работы уже отмечены.

## Заполнение ячейки месячной таблицы

Выберите тип занятости и полигон. Список работ автоматически фильтруется по двум
условиям: работа разрешена должности сотрудника и допускает выбранный тип занятости.
Работы в списке разделены по блокам. При смене типа неподходящая работа снимается.
Номер полигона сохраняется отдельно от типа и работы.

Работу можно оставить «Выбрать позже» и сохранить день только с типом и полигоном.
Такая ячейка показывает код места и небольшую отметку; при открытии написано, что
работа ещё не выбрана. Позже откройте день и дополните его работой.
На промежуточных этапах это разрешено. Перед окончательным формированием система
потребует указать работу для каждого заполненного дня, чтобы не создавать табели
с пропущенными шифрами. Пустая ячейка по-прежнему означает, что сотрудник не работал.
День с выбранными типом и полигоном учитывается в числе отработанных дней.

Ограничения проверяются сервером, а не только списком выбора в браузере.
Нерабочие дни, уникальность месяца, однократная генерация, права ролей и исторические
расчёты предыдущего выпуска сохранены.

## Права

В редактор ролей добавлены Подразделения и Блоки работ: просмотр, создание,
редактирование и исключение. Назначение работ должностям использует разрешение
«Работы общих таблиц → Настраивать ограничения по должностям».
Для редактирования трёх квадратов требуется изменение работ общих таблиц.
Необходимый просмотр зависимых справочников добавляется автоматически.
Системный администратор имеет полный доступ.

/home/admin/backups/uchet-tabelya/. .env, Compose и Caddy не заменяются. ИСУ и
учёт оборудования не перезапускаются. Данные не очищаются.

## Обновление через GitHub

Загрузите файлы архива с сохранением структуры в папку uchet-tabelya репозитория.
Новый обязательный модуль этого выпуска — server/catalogues.mjs. Архив содержит
и необходимые серверные файлы версии 2.0. Обновление только app.js не подходит.

В одном SSH-сеансе:

```bash
TABEL_UPDATE=$(mktemp -d /home/admin/tabel-update-XXXXXX) &&
git clone --depth 1 https://github.com/Greenl1s/imcstroy.git "$TABEL_UPDATE" &&
test -f "$TABEL_UPDATE/uchet-tabelya/server/catalogues.mjs" &&
test -f "$TABEL_UPDATE/uchet-tabelya/server/monthly.mjs" &&
test -f "$TABEL_UPDATE/uchet-tabelya/server/production-calendar.mjs" &&
test -f "$TABEL_UPDATE/uchet-tabelya/server/grid-xlsx.mjs" &&
cd /home/admin/apps/uchet-tabelya &&
mkdir -p /home/admin/backups/uchet-tabelya &&
tar -czf "/home/admin/backups/uchet-tabelya/source-before-2.1-$(date +%Y%m%d-%H%M%S).tar.gz" public server package.json &&
docker compose -p uchet-tabelya -f compose.yml -f compose.proxy.yml exec -T timesheets node server/backup.mjs &&
cp "$TABEL_UPDATE/uchet-tabelya/public/app.js" public/app.js &&
cp "$TABEL_UPDATE/uchet-tabelya/public/style.css" public/style.css &&
cp "$TABEL_UPDATE/uchet-tabelya/public/index.html" public/index.html &&
cp "$TABEL_UPDATE/uchet-tabelya/server/server.mjs" server/server.mjs &&
cp "$TABEL_UPDATE/uchet-tabelya/server/workflow.mjs" server/workflow.mjs &&
cp "$TABEL_UPDATE/uchet-tabelya/server/permissions.mjs" server/permissions.mjs &&
cp "$TABEL_UPDATE/uchet-tabelya/server/monthly.mjs" server/monthly.mjs &&
cp "$TABEL_UPDATE/uchet-tabelya/server/catalogues.mjs" server/catalogues.mjs &&
cp "$TABEL_UPDATE/uchet-tabelya/server/production-calendar.mjs" server/production-calendar.mjs &&
cp "$TABEL_UPDATE/uchet-tabelya/server/grid-xlsx.mjs" server/grid-xlsx.mjs &&
cp "$TABEL_UPDATE/uchet-tabelya/server/xlsx.mjs" server/xlsx.mjs &&
cp "$TABEL_UPDATE/uchet-tabelya/package.json" package.json &&
docker compose -p uchet-tabelya -f compose.yml -f compose.proxy.yml up -d --build --no-deps timesheets &&
curl --retry 8 --retry-connrefused --retry-delay 1 -fsS http://127.0.0.1:3180/tabel/api/health
```

Если версия 2.0 ещё не устанавливалась, после обновления сначала заполните
подразделения, должности и коэффициенты сотрудников, среднемесячную сумму,
полигоны, блоки работ и разрешения. Только затем создавайте первую месячную таблицу.
