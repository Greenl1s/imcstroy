# Табельный учёт 2.2.0

## Что изменилось

Общая месячная таблица сразу доступна в Планировании, Верификации и Контроле.
Это одна запись: изменение дня в любом разрешённом разделе видно в остальных.
Открытая таблица, списки месяцев и главная проверяют изменения каждые 3 секунды.
Доступ к разделам, редактированию, подтверждению и выгрузке задаётся прежними правами ролей.
Зарплатные данные доступны только в интерфейсе Контроль и его выгрузке.

У каждого заполненного дня теперь три отдельных подтверждения с автором и временем.

- Бледный синий / красный / зелёный фон — командировка / офис / общая занятость.
- Курсив — ячейка ещё не подтверждена в Планировании.
- После подтверждения Планирования курсив исчезает.
- Подтверждение Верификации делает фон более насыщенным.
- Подтверждение Контроля отмечается маленькой галочкой.
- Жирные цифры — вид работы указан; обычные — его ещё нужно выбрать.

Подтвердить день на следующем этапе можно только после предыдущего подтверждения.
При изменении данных дня сбрасываются ВСЕ его подтверждения; остальные дни не затрагиваются.
Изменённый день нужно повторно подтвердить в Планировании, Верификации и Контроле.
Пустые дни подтверждать не требуется: сотрудник не работал.

Сверху есть счётчики подтверждённых дней каждого этапа и кнопка массового подтверждения.
В Контроле кнопка «Сформировать табель» подтверждает все заполненные дни контроля и создаёт
табели по полигонам одной операцией. Для этого каждый заполненный день должен пройти
Планирование и Верификацию и иметь вид работы. После формирования редактирование закрывается.

Цвета закреплены по типам занятости. Из настройки убран выбор цвета; сервер также
игнорирует попытки изменить палитру. Коды и названия типов по-прежнему настраиваются
для новых месяцев. Ранее сформированные табели сохраняют свои данные и цвета.

## Как редактировать

1. Откройте месяц в нужном разделе.
2. Левой кнопкой нажмите рабочий день. Рядом с сеткой откроется редактор,
   а сама ячейка станет полем ввода. На небольшом экране редактор располагается под сеткой.
3. Можно выбрать тип, полигон и необязательный вид работы в редакторе.
   Или ввести код прямо в ячейке: `12` = тип 1 / полигон 2; `212` = тип 2 / полигон 12;
   `20` = тип 2 / полигон 0. Полигон должен существовать в справочнике.
4. Нажмите Enter в ячейке или «Сохранить день». Для отказа от черновика нажмите Escape
   в ячейке или крестик редактора. Печать без сохранения данные сервера не меняет.
5. Нажмите «Подтвердить выбранные» в редакторе для подтверждения на текущем этапе.

Группа ячеек:

1. Правой кнопкой мыши отметьте нужные рабочие дни: появится синяя рамка.
2. Повторная правая кнопка на том же дне снимает отметку.
3. Левой кнопкой откройте любую из выбранных ячеек.
4. Введите общий код и при необходимости работу; сохранение применит их ко всей группе.
   «Очистить выбранные» очистит всю группу.
5. Можно подтвердить всю выбранную группу отдельной кнопкой.

Если левой кнопкой нажать день вне выбранной группы, откроется только этот день.
Список работ содержит только работы, разрешённые ВСЕМ выбранным сотрудникам для
указанного типа занятости. Сервер проверяет каждую ячейку. Если хотя бы одна неверна,
не сохраняется вся группа. Выходные и праздничные дни заполнить нельзя.

При одновременной работе изменения других пользователей обновляются автоматически.
Открытый черновик не перезаписывает серверные данные: при несовпадении версии сохранение
отклоняется. Заново откройте день, чтобы увидеть актуальное значение, и повторите ввод.

## Совместимость

Обновление включает необходимые файлы прежних версий 2.0–2.1.1:
подразделения, блоки работ, назначения должностям и сворачивание блоков сохраняются.
При первом запуске ранее пройденные этапы месячных таблиц переносятся в подтверждения
их заполненных дней. На этапе Верификация сохраняется подтверждение Планирования;
на этапе Контроль — Планирования и Верификации. Готовые табели не пересоздаются.
Старая пробная форма до появления месячной сетки остаётся совместимой; её можно
перевести в месячную форму прежней кнопкой администратора.

Обновлять только app.js нельзя. Новый обязательный модуль: server/cell-state.mjs.
База переносится автоматически при запуске. Перед установкой обязательно выполните
резервное копирование из команд ниже. После обновления всем пользователям нужен Ctrl+F5.

Сначала передайте архив с компьютера. В PowerShell Windows:

На сервере в SSH-терминале:

```bash

mkdir -p /home/admin/backups/uchet-tabelya &&

python3 -m zipfile -e /home/admin/uchet-tabelya-changes-2.2.0.zip /home/admin/apps/uchet-tabelya &&
docker compose -p uchet-tabelya -f compose.yml -f compose.proxy.yml up -d --build --no-deps timesheets &&
```

/home/admin/backups/uchet-tabelya/. .env, Compose и Caddy не заменяются. ИСУ и
учёт оборудования не перезапускаются. Данные не очищаются.
