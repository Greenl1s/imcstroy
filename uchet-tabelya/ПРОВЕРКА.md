# Результаты проверки

Дата: 20 октября 2026 года. Версия 1.1.0.

`node --check public/app.js` — ошибок синтаксиса нет.

`npm test` — 25 проверок пройдены, 0 ошибок. Проверен рабочий цикл через HTTP API с реальной временной SQLite-базой: первый администратор, сотрудник, справочники, должности, разрешения, создание и заполнение табеля, обычная работа и командировка, завершение, запрет редактирования завершённого табеля, возврат только администратором, конфликт версий, архивирование справочников и сохранность после перезапуска. Дополнительно проверены CSRF и отказ неавторизованным запросам.

Для серверного размещения проверены `/api/health`, код первоначальной настройки, запрет постороннего Origin при настроенном HTTPS-адресе и флаги Secure/HttpOnly/SameSite сессионной cookie. Сам TLS в этом тесте не поднимался: HTTPS завершается на внешнем Caddy. Резервная копия создавалась при работающем сервере и SQLite WAL, затем отдельный сервер был запущен на копии: табель и вход сохранились. Проверено, что скрипт отказывается перезаписывать существующую копию и рабочую базу.

Конфигурации проверены официальным Docker Compose 5.6.0 командой `config --format json`: основной файл, объединение с `compose.proxy.yml`, привязка порта только к loopback, изменение порта хоста, отдельное имя тома, ограничение памяти, алиас сервиса и обязательность имени внешней сети. Docker daemon для этой проверки не запускался; сборка образа и работа контейнеров на Linux этим не подтверждаются.

Экспорт `.xlsx` независимо прочитан библиотекой openpyxl. Проверены 29 дней февраля 2028 года, 59 колонок, подпись «Иванов И.И.», обычная работа, командировка, соседние прочерки и закрепление шапки. Автоматические тесты также проверяют объединённые заголовки и безопасное сохранение строк, начинающихся со знака `=`.

Ограничения проверки: локальный сайт не открылся из браузера Codex из-за блокировки соединения с предпросмотром. Визуальная проверка на компьютере и телефоне, ручные клики и реальное скачивание через браузер не подтверждены. Docker-конфигурация подготовлена, запуск Docker в этом окружении не проверялся. Проверки не являются полноценным аудитом безопасности.

Рабочая база поставляется пустой. Проверочные базы, учётные записи, журналы и персональные данные в комплект исходников не включены. Действующая ИСУ не изменялась.
