# Табельный учёт 2.4.1

## Денежные показатели только в Контроле

В Планировании и Верификации убраны все денежные показатели:

- «Запланированные затраты» и «Подтвержденные затраты» на карточках месяцев.
- Суммы в заголовке открытой сводной таблицы.
- Финансовые строки итогов и зарплатные столбцы в Excel этих стадий.
- Денежные итоги, ставка, коэффициенты и начисления из ответов API этих стадий.

Это действует и для администратора, если он открыл Планирование или Верификацию,
а также для уже завершённых месячных таблиц в этих разделах.
При переходе в Контроль денежные итоги и индивидуальные зарплатные колонки
отображаются как раньше. В его Excel сохранены плановые и фактические дни,
начисления, формулы и оба итога затрат.

Изменение касается доступа и отображения. Ставки, коэффициенты, расчёты,
сохранённые дни и готовые табели не удаляются и не пересчитываются по новым правилам.
Поведение выделения, Escape, Backspace, Верификации и формирования табелей сохранено.

Списки таблиц и их синхронизация теперь запрашивают данные выбранной стадии.
В ответе для Планирования и Верификации денежных полей нет, а не только скрыты
их надписи в браузере. Для получения данных Контроля сервер проверяет право доступа.

## Проверка

Пройдены 64 автоматические проверки, включая отсутствие сумм в интерфейсе,
API и Excel Планирования / Верификации и сохранение расчётов в Контроле.
После установки всем пользователям нужно нажать Ctrl+F5, чтобы загрузить новый интерфейс.

Архив накопительный: содержит необходимые файлы предыдущих выпусков 2.0–2.4.0.
Устанавливайте его целиком, с обязательным модулем server/summary-xlsx.mjs.

## Установка архива

Сначала передайте архив с компьютера. В PowerShell Windows:

```powershell
scp "C:\Users\user\Documents\ChatGPT\Ниц\outputs\uchet-tabelya-changes-2.4.1.zip" admin@213.171.26.248:/home/admin/
```

На сервере в SSH-терминале:

```bash
cd /home/admin/apps/uchet-tabelya &&
mkdir -p /home/admin/backups/uchet-tabelya &&
tar -czf "/home/admin/backups/uchet-tabelya/source-before-2.4.1-$(date +%Y%m%d-%H%M%S).tar.gz" public server package.json &&
docker compose -p uchet-tabelya -f compose.yml -f compose.proxy.yml exec -T timesheets node server/backup.mjs &&
python3 -m zipfile -e /home/admin/uchet-tabelya-changes-2.4.1.zip /home/admin/apps/uchet-tabelya &&
docker compose -p uchet-tabelya -f compose.yml -f compose.proxy.yml up -d --build --no-deps timesheets &&
curl --retry 8 --retry-connrefused --retry-delay 1 -fsS http://127.0.0.1:3180/tabel/api/health
```

Ожидается `{"ok":true}`. Откройте https://files.imcstroy.ru/tabel/ и нажмите Ctrl+F5.
Резервная копия базы находится в прежнем Docker volume, исходников — в папке
/home/admin/backups/uchet-tabelya/. .env, Compose и Caddy не заменяются. ИСУ и
учёт оборудования не перезапускаются. Данные не очищаются.

## Обновление через GitHub

Загрузите файлы архива с сохранением структуры в папку uchet-tabelya репозитория.

и необходимые серверные файлы версии 2.0. Обновление только app.js не подходит.

полигоны, блоки работ и разрешения. Только затем создавайте первую месячную таблицу.
