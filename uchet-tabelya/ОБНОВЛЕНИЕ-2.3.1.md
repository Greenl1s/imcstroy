# Табельный учёт 2.3.1

## Дополнение 2.3.1

Заголовок левой панели «Согласование» заменён на «Сводные таблицы».
Escape снимает всё выделение ячеек, в том числе выделенный диапазон,
закрывает редактор и отменяет его несохранённый черновик. Если выделение
ещё протягивается мышью, Escape также прекращает протягивание.
Сохранённые значения дней не очищаются.
В версии 2.3.1 повторно пройдены 11 проверок интерфейса и отдельно проверены
Escape при выборе, редактировании и протягивании.

## Изменения базового выпуска 2.3.0

Все существующие работы общих таблиц при первом запуске обновления отмечаются
для всех должностей. Новая работа автоматически отмечается для каждой должности,
а новая должность получает все действующие работы. После этого можно вручную
снять ненужные галочки: они не вернутся при следующем перезапуске.
Три ограничения по типам занятости у работ настраиваются отдельно, как раньше.

Кнопка создания переименована в «Создание сводной таблицы».

Сводные таблицы во всех трёх разделах представлены одинаковыми карточками:
название, месяц, число сотрудников и общая сумма. Сумма — это сумма начислений
«З/п за отработанные дни» всех сотрудников. Она пересчитывается сервером при
каждом заполнении или очистке дня, с коэффициентами и ставкой сохранённого месяца.
Открытая таблица получает результат сразу после сохранения. Остальные пользователи
видят изменения при автоматическом обновлении каждые 3 секунды.

Индивидуальные коэффициенты и зарплаты остаются доступными только в Контроле;
общая сумма видна во всех трёх разделах по согласованному требованию.

## Выделение, ввод и очистка

- Один левый щелчок по дню выбирает его; повторный снимает выделение.
- Протяните левой кнопкой мыши от начальной до конечной ячейки: выделится
  прямоугольник сотрудников и дат. Нерабочие дни не включаются.
- Ctrl при начале протягивания добавляет ещё один диапазон к уже выбранным.
- Правая кнопка мыши по выбранной ячейке открывает редактор для всей группы.
- Двойной левый щелчок тоже открывает ввод прямо в ячейке. Это работает
  в Планировании, Верификации и Контроле при наличии права редактирования.
- Если открыть день вне выбранной группы, редактор переключится только на этот день.
- Введите код (например, 212 — тип 2, полигон 12), выберите необязательный вид работы
  и нажмите Enter либо «Сохранить». Значение применится ко всей выбранной группе.
- Backspace или Delete, когда выбран день или группа, сразу очищает их значения.
  Это не удаляет сотрудника, месяц или саму таблицу.
- Если редактируется код внутри ячейки, полное стирание кода Backspace тоже сразу
  сохраняет пустой день. Для частично изменённого непустого кода нужен Enter / «Сохранить».
- Escape снимает весь выбор и закрывает несохранённый черновик редактора.

Ввод и подтверждение всей группы атомарны: если хотя бы один день нельзя изменить,
вся операция отклоняется. Права должностей и типов занятости проверяются сервером.
Выходные и праздничные дни остаются закрытыми. Конфликт версий не позволяет
перезаписать изменения другого сотрудника старым черновиком.

## Согласование

Курсив полностью убран из сводной таблицы и её Excel-выгрузки.

Планирование: заполняем дни, без подтверждения ячеек. Изменения сразу видны
в Верификации и Контроле — это одна общая таблица, а не три копии.

Верификация: подтверждаем один день, выбранную группу или все заполненные дни.
Подтверждённые дни имеют яркий фон. До подтверждения фон бледный.
Код жирный, если указан вид работы, и обычный, если работа ещё не выбрана.

Контроль: просматриваем и при необходимости редактируем дни, затем нажимаем
«Сформировать табель». Отдельного подтверждения ячеек здесь нет.
Для формирования все заполненные дни должны пройти Верификацию и иметь вид работы.

Изменение дня на любом этапе сбрасывает верификацию только этого дня.
После исправления его нужно заново подтвердить в Верификации.
Пустые дни подтверждать не требуется: сотрудник в этот день не работал.
Готовые табели остаются окончательными; повторное формирование запрещено.

При обновлении сохраняются прежние подтверждения Верификации. Отметки
подтверждения Планирования и Контроля больше не используются.
Ранее сформированные табели, их шифры и расчёты не пересоздаются.

## Excel

Оформление сводной выгрузки построено по присланному листу «НТС 1.1»:
Calibri 11, двухстрочная шапка со строками 47,25 и 24 пункта,
те же ширины основных столбцов и дат, тонкая чёрная сетка, объединённый заголовок
периода и закрепление D4. Примечания размещены под датами шрифтом Times New Roman,
как в образце. Цвет дней отражает тип занятости и верификацию из системы.

Месяц, границы периода, число дат и сотрудников берутся из текущей сводной таблицы.
Сотрудники, должности, коэффициенты, коды и расчёты исходного Excel не копируются.
Для месяцев с 28, 29 или 30 днями сетка и расположение итогов адаптируются.

В Контроле выгружаются коэффициент, месячная и дневная зарплата, число отработанных
дней и начисление. Формулы ссылаются только на данные самого экспортированного файла,
без внешнего имени «база3» и фиксированного деления на 21 день. Количество рабочих
дней берётся из сохранённого производственного календаря месяца.
Число дней считается по непустым ячейкам; пустые ячейки действительно пусты.

В Планировании и Верификации индивидуальные зарплатные столбцы исключены,
общая сумма остаётся. Это соответствует отдельно подтверждённому ограничению доступа.
Выгрузка уже сформированных табелей по полигонам сохраняет свой прежний формат.

## Проверка

Для базового выпуска 2.3.0 пройдены 64 автоматические проверки: рабочие процессы, права, суммы, подтверждение
только верификацией, групповые операции, обработчики мыши и Backspace, новые работы
и должности, миграции и сохранность истории, месяцы разной длины и Excel.
Тестовая Excel-выгрузка дополнительно импортирована, пересчитана и отрисована:
ошибок формул не найдено, итог сопоставлен с независимым серверным расчётом.
Полная ручная проверка приложения в браузере выполняется после установки.

Обновление устанавливается целиком: обязательный новый серверный модуль —
server/summary-xlsx.mjs. Обновлять один app.js нельзя.

## Установка архива

Сначала передайте архив с компьютера. В PowerShell Windows:

```powershell
scp "C:\Users\user\Documents\Codex\2026-09-19\new-chat\outputs\uchet-tabelya-changes-2.3.1.zip" admin@213.171.26.248:/home/admin/
```

На сервере в SSH-терминале:

```bash
cd /home/admin/apps/uchet-tabelya &&
mkdir -p /home/admin/backups/uchet-tabelya &&
tar -czf "/home/admin/backups/uchet-tabelya/source-before-2.3.1-$(date +%Y%m%d-%H%M%S).tar.gz" public server package.json &&
docker compose -p uchet-tabelya -f compose.yml -f compose.proxy.yml exec -T timesheets node server/backup.mjs &&
python3 -m zipfile -e /home/admin/uchet-tabelya-changes-2.3.1.zip /home/admin/apps/uchet-tabelya &&
docker compose -p uchet-tabelya -f compose.yml -f compose.proxy.yml up -d --build --no-deps timesheets &&
curl --retry 8 --retry-connrefused --retry-delay 1 -fsS http://127.0.0.1:3180/tabel/api/health
```

Ожидается `{"ok":true}`. Откройте https://files.imcstroy.ru/tabel/ и нажмите Ctrl+F5.
Резервная копия базы находится в прежнем Docker volume, исходников — в папке
/home/admin/backups/uchet-tabelya/. .env, Compose и Caddy не заменяются. ИСУ и
учёт оборудования не перезапускаются. Данные не очищаются.
