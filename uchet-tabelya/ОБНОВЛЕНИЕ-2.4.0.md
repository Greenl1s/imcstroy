# Табельный учёт 2.4.0

## Плановые и подтверждённые затраты

В Контроле после дат стоят четыре колонки в таком порядке:

1. «Запланированные отработанные дни» — число рабочих дней полного месяца
   по сохранённому производственному календарю, без выходных и праздников.
2. «Запланированные з/п за отработанные дни» — плановые дни × дневная зарплата.
3. «Отработано дней» — прежнее число заполненных дней сотрудника.
4. «З/п за отработанные дни» — прежнее начисление за заполненные дни.

Дневная ставка используется без промежуточного округления; денежный итог
округляется до копеек. Поэтому плановая сумма за полный месяц совпадает
с сохранённой месячной зарплатой сотрудника с учётом его коэффициента.
Нулевой коэффициент даёт нулевую сумму, а не пропуск.

Карточки сводных таблиц на всех трёх стадиях теперь показывают две строки:

- «Запланированные затраты» — сумма плановой зарплаты всех сотрудников таблицы.
- «Подтвержденные затраты» — прежняя «Общая сумма», сумма начислений за заполненные дни.

«Подтвержденные затраты» — переименование существующего показателя,
без изменения его формулы: отдельной фильтрации по отметкам Верификации нет.
При добавлении или очистке дней этот итог обновляется после сохранения;
у других пользователей — при очередной синхронизации (каждые 3 секунды).
Плановый итог от заполнения дней не меняется: он относится к полному месяцу.
Если у всех пустые дни, фактические затраты равны нулю, а плановые сохраняются.

В шапке открытой таблицы также видны оба итога. Индивидуальные плановые
и фактические зарплатные показатели доступны только в Контроле.
В Планировании и Верификации показываются только общие затраты.

Расчёты используют ставку, коэффициенты и календарь, сохранённые при создании
месяца. Изменение текущих настроек не переписывает показатели прошлых месяцев.
Новые показатели вычисляются автоматически и для уже созданных месячных таблиц.
Существующие фактические начисления и готовые табели не пересоздаются.

## Excel

В выгрузке Контроля добавлены те же две плановые колонки перед двумя
фактическими. Для октября из 31 дня это AM и AN, затем AO и AP.
Для другого месяца положение итогов меняется вместе с числом дней.
Под таблицей выводятся отдельные строки «Запланированные затраты»
и «Подтвержденные затраты» с формулами SUM по соответствующим столбцам.
Плановая зарплата рассчитывается формулой из числа дней и дневной ставки.

В выгрузке Планирования и Верификации остаются скрытыми все индивидуальные
зарплатные колонки. Две общие суммы сохраняются; поля итогов достаточно широкие,
чтобы денежные значения не превращались в ###.

## Совместимость и проверка

Архив включает изменения 2.3.0 и 2.3.1: выбор работ по умолчанию,
выделение и протягивание левой кнопкой, редактирование правой или двойным
щелчком, очистку Backspace / Delete, снятие выделения Escape,
подтверждение только в Верификации и заголовок «Сводные таблицы».

Пройдены 64 автоматические проверки. Дополнительно тестовая Excel-выгрузка
пересчитана и визуально проверена: плановые колонки стоят перед фактическими,
итоги совпадают с сервером, ошибок формул нет.
Полная ручная проверка установленного приложения в браузере выполняется после обновления.

Обновление нужно устанавливать целиком. В комплект входит обязательный модуль
server/summary-xlsx.mjs; обновлять только public/app.js нельзя.

## Установка архива

Сначала передайте архив с компьютера. В PowerShell Windows:

```powershell
scp "C:\Users\user\Documents\Codex\2026-09-19\new-chat\outputs\uchet-tabelya-changes-2.4.0.zip" admin@213.171.26.248:/home/admin/
```

На сервере в SSH-терминале:

```bash
cd /home/admin/apps/uchet-tabelya &&
mkdir -p /home/admin/backups/uchet-tabelya &&
tar -czf "/home/admin/backups/uchet-tabelya/source-before-2.4.0-$(date +%Y%m%d-%H%M%S).tar.gz" public server package.json &&
docker compose -p uchet-tabelya -f compose.yml -f compose.proxy.yml exec -T timesheets node server/backup.mjs &&
python3 -m zipfile -e /home/admin/uchet-tabelya-changes-2.4.0.zip /home/admin/apps/uchet-tabelya &&
docker compose -p uchet-tabelya -f compose.yml -f compose.proxy.yml up -d --build --no-deps timesheets &&
curl --retry 8 --retry-connrefused --retry-delay 1 -fsS http://127.0.0.1:3180/tabel/api/health
```

Ожидается `{"ok":true}`. Откройте https://files.imcstroy.ru/tabel/ и нажмите Ctrl+F5.
Резервная копия базы находится в прежнем Docker volume, исходников — в папке
/home/admin/backups/uchet-tabelya/. .env, Compose и Caddy не заменяются. ИСУ и
учёт оборудования не перезапускаются. Данные не очищаются.

В комплект обязательно входит server/summary-xlsx.mjs. Архив содержит
и необходимые серверные файлы версии 2.0. Обновление только app.js не подходит.
