Добавить эксперта

Заведём папку эксперта и подпапку «Приложения». Сведения — пункты биографии и подтверждающие их сканы — заполняются отдельно, кнопкой «Сведения об эксперте» в этой же папке.

Сведения об эксперте

Каждый пункт в файле сведений начинается с «-». Сканы принимаем картинками (JPG, PNG) — только их можно вшить в Word. Сохранение пересобирает оба файла в папке эксперта, поэтому править их в Word смысла нет: следующее сохранение перепишет.

Добавить гарантийное письмо

Файл сохранится прямо в этот проект («Планирование проекта / ГП»). Суд и номер дела подставятся из карточки проекта — их можно поправить вручную.
